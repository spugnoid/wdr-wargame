# German 7.5 cm PaK 40 — Technical Data and 1943 Organizational Context

Research pass only, following the format of `counters/toe/british_vehicles_1943.md`.
No AV/PEN numbers or K-factor fits are computed here — that is a separate step
using this project's own `fit_gun_curve` (see `counters/armor_calc/formulas.py`).
This file gathers raw, cited inputs for the project's **first towed anti-tank
gun** (as opposed to a vehicle-mounted gun): muzzle velocities, calibration
points, and 1943 organizational/crew context, for the German 7.5 cm PaK 40
firing PzGr 39 (APCBC) and PzGr 40 (APCR/tungsten).

## PzGr 39 (APCBC) — the standard nature

### Muzzle velocity
Two figures found, from two different source families (a real, flaggable
discrepancy, same pattern as this project's existing 17-pounder MV note):
- **790 m/s = 2,592 fps** — German factory/ordnance figure (Nachrichtenblatt
  zur Panzerbeschusstafel 7,5 cm Pak 40 L/46, Nov 1942), reproduced by both
  Wikipedia and Panzerworld.
- **792 m/s = 2,598 fps** — Aberdeen/British-Ordnance-Board test figure
  (Hoffschmidt 1979, via panzer-war.com `tGer01`). Functionally identical to
  the German figure (6 fps / ~0.2% apart) — this one is not a meaningful
  discrepancy, just noted for completeness; either value is fine to use.

### K-factor
**Not found**, in the sense this project uses the term (a velocity-retardation
constant already fit and stated, ready to drop into `guns.csv`). Searched
Wikipedia, Panzerworld, Tank Archives, three Axis History Forum threads (via
search snippets; direct fetch blocked), The Miniatures Page, and panzer-war.com.
The single genuine Bird & Livingston K-factor number surfaced anywhere in this
search (panzer-war.com's page, "Bird's Ballistic 'K' factor 2600") is stated
explicitly for the 75mm/L48 **HE** shell, not PzGr 39 APCBC — a different
ammunition nature, not transferable. One Axis History Forum search snippet
asserts Bird & Livingston's book *does* cover this gun/round and gives
consistently higher penetration than German test data, confirming the book
has *something* on PaK 40, but no actual K value or table was recoverable
from a snippet — the forum pages themselves returned HTTP 403 to direct
fetch. Per this project's own `guns.csv` confidence_note pattern (every
existing gun's K-factor is described as a curve fit, not a book-sourced
constant, with the 6pdr/17pdr rows flagged only because their fits needed
special handling), the expectation should be the same here: fit K from the
calibration points below via `fit_gun_curve`, not look one up.

## PzGr 40 (APCR/tungsten) — confirmed historically fielded, ammo shortages noted

The PaK 40 did fire PzGr 40 (tungsten-cored APCR), as the task expected;
tungsten supply was chronically short in German service from 1942 on and
PzGr 40 issue was rationed accordingly (well-established general point in
the secondary literature; not independently re-verified with a fresh citation
this session beyond what's implicit in every source below listing it as a
distinct, named nature).

### Muzzle velocity
Same pattern of two source families as PzGr 39, but here the discrepancy is
larger and genuinely unresolved:
- **990 m/s = 3,248 fps** — German factory figure (Nachrichtenblatt, Nov 1942),
  Wikipedia and Panzerworld agree on this figure.
- **933 m/s = 3,060 fps** — Aberdeen/British Ordnance Board figure (Hoffschmidt
  1979, via panzer-war.com `tGer01`); also the figure implied by Wikipedia's
  own uncited Table 2 (933 m/s stated directly next to the 154mm/500m figure).
  This is a **57 m/s / ~2.9% gap** from the German-document figure — a real,
  not-resolved discrepancy, flagged rather than silently averaged (same
  practice as this project's existing 17-pounder APCBC MV note).

### K-factor
Not found, same situation and same search coverage as PzGr 39 above.

### Calibration points

**Set 1 — 30° from vertical, German period document (Wikipedia Table 1),
MV 990 m/s:**
- (100 m, 143 mm, 30°), (500 m, 120 mm, 30°), (1000 m, 97 mm, 30°),
  (1500 m, 77 mm, 30°)

**Set 2 — Aberdeen/British Ordnance Board (Hoffschmidt 1979, via panzer-war.com
`tGer01`), ranges in yards, MV 933 m/s:**
- 0°: (0 yd, 176 mm), (500 yd, 154 mm), (1000 yd, 133 mm), (1500 yd, 115 mm),
  (2000 yd, 98 mm), (2500 yd, 83 mm)
- 30°: (0 yd, 137 mm), (500 yd, 115 mm), (1000 yd, 96 mm), (1500 yd, 80 mm),
  (2000 yd, 66 mm), (2500 yd, 53 mm)

**Cross-reference only:** panzer-war.com's normalized `tR01` table does **not**
include a PzGr 40 row for the 75mm/L46 PaK 40 specifically (only for the
75mm/L48 KwK 40, a related but different gun/mount) — not reproduced here to
avoid conflating the two guns' tungsten performance, even though they likely
fired near-identical PzGr 40 ammunition.

## Crew and 1943 Organizational Context

`counters/toe/germany_1943.md` was checked first, per the task brief, to
avoid duplicating existing coverage: **it does not cover this at all.** That
file is explicitly scoped to the Rifle Squad/Platoon/Company (infantry only)
and mentions the Company-level "Anti-tank Rifle Squad" (3× Panzerbüchse
anti-tank rifle, NOT a PaK gun) only in passing. Neither the PaK-gun-armed
Regimental Anti-tank Company nor the divisional Panzerjäger-Abteilung is
discussed there — this section is genuinely new ground, not a duplicate.

### Crew size
**6 men per gun.** Source: Foss, Christopher, *Jane's Pocket Book of Towed
Artillery*, Collier, 1977, p. 27 (via Wikipedia's "7.5 cm Pak 40" infobox
citation). Single source, but a specific, real, page-cited reference book —
not a wargaming-forum guess.

### Organizational placement — two distinct tiers, both real, both PaK-40-relevant

**1. Divisional Panzerjäger-Abteilung (organic to the infantry division).**
Per TM-E 30-451 (1 Sept 1943 US Army handbook), para. 9: every "Infantry
division of the normal type" is organized around "a headquarters, a
reconnaissance battalion, three infantry regiments, an artillery regiment,
an engineer battalion, **an antitank battalion**, a signal battalion, and
services" — i.e. the Panzerjäger-Abteilung is explicitly organic to the
division, not a separate/attached higher-echelon formation. Para. 64e and
Figure 86 give its composition **as of September 1943**: a headquarters,
**three antitank companies, and one antiaircraft company**, totaling 599
personnel, 12× 20mm AA/AT guns, and **24× 50mm antitank guns (PaK 38)** —
i.e., per this specific 1 September 1943 snapshot, the *standard* divisional
battalion is still shown as 50mm-gun-armed, not yet PaK 40. Para. 65c
separately describes a distinct "heavy antitank battalion" (schwere
Panzerjägerabteilung): *"organized in the same manner as the regular
divisional antitank units, except that their antitank companies are equipped
with 7.5-cm antitank guns instead of 50-mm."* This is the clearest, most
specific primary-source statement found this session tying PaK 40 to a named
1943 organizational slot — but it's explicitly a *heavy* variant unit, not
asserted as the universal divisional standard as of the handbook's own
September 1943 date.

**2. Infantry Regiment's own Anti-tank Company** (separate from the divisional
battalion above, held at regiment level). Per Kennedy (bayonetstrength.uk):
*"The Infantry Regiment included an Anti-tank Company, which could be
equipped with a bewildering mixture of weapons (3.7-cm, 5-cm and 7.5-cm
German Pak, captured and repurposed 7.62-cm Russian field cannons, various
models of 4.7-cm gun), themselves issued in varying combinations to units."*
No platoon/gun-count breakdown for this specific company in its 1943 (pre-
Type44) form was found in Kennedy's document — only the later Type 1944
reorganization is broken out in detail there (two Panzerschreck platoons of
18 launchers each + one platoon of 3 towed PaK 40 guns), which is explicitly
described as a *replacement* for the earlier mixed-weapons company and is
outside this project's 1943 scope.

**Net read:** by calendar-1943, a PaK 40 in the field could plausibly belong
to *either* tier — the division's own Panzerjäger-Abteilung (increasingly,
per Wikipedia's general PaK 40 prose, "the standard German anti-tank gun of
the latter part of the war," progressively replacing the 50mm PaK 38 as
production allowed through 1943) *or* one of the regimental Anti-tank
Company's platoons — and no source found this session pins down an exact
divisional-standard reorganization date within 1943 for the switch from
50mm to 75mm at the *divisional-battalion* level specifically (only the
regimental Type44/Dec-1943-era reorganization has a clean date, and that's
technically outside this project's nominal 1943 window). This is left as
an open question rather than guessed at.

### Morale/quality tier
**Not found, genuinely.** No source located this session made any explicit
claim, TOE-linked or otherwise, about German 1943 antitank gun crews being
rated as "veteran," "regular," or any other specific quality tier relative to
ordinary infantry. It's a commonly repeated informal claim in wargaming
circles that antitank crews were experienced specialists, but nothing
citable to back a specific tier assignment was found in TM-E 30-451,
Kennedy's document, or general search this session — flagged as an open
question rather than asserted.

## Historical Validation Data

**No single, precisely-dated-and-ranged combat anecdote of a PaK 40 killing a
specific named Sherman/T-34/Churchill was found this session** — this is a
genuine gap, not an oversight. What was found instead:

- Wikipedia's own summary assessment (uncited to a specific engagement):
  the PaK 40 "was effective against almost every Allied tank until the end
  of the war, only struggling to penetrate heavier vehicles like the Russian
  IS tanks, the American M4A3E2 Sherman 'Jumbo' assault tank and M26
  Pershing, and later variants of the British Churchill tank" — a general
  qualitative claim, not a specific incident.
- Kasserine Pass / Sidi Bou Zid, Tunisia, February 1943 is the most
  commonly-surfaced real 1943 case of German antitank guns inflicting heavy
  Sherman losses in an ambush (CCC of US 1st Armored Division lost 46 of 52
  M4 Shermans per Wikipedia's "Battle of Sidi Bou Zid" article), but every
  account surfaced this session emphasizes **88mm** guns (Flak 36/Flak 18 in
  the antitank role) as the principal weapon, with only a passing mention of
  "47mm and 88mm" guns present — no PaK 40-specific range or kill was
  isolated from the general ambush.
- Tank Archives' "Pak 40 Penetration Tables" post (see Sources) gives
  German-issued **tactical doctrine** for engaging T-34/KV, e.g. "AP at the
  gun mantlet from 1000m; AP at the driver's hatch or connecting bar at
  100-500m" — this describes prescribed engagement ranges, not a documented
  actual kill, but is at least a dated (through 15 March 1943), archival
  (CAMD RF), 1943-era primary-flavored source about how PaK 40 crews were
  told to fight T-34s specifically.

**Recommended in-project cross-check instead**, using armor data already in
this project's own `counters/armor_calc/data/vehicles.csv` (no new sourcing
needed, just noted here for whoever runs the fit): T-34 Model 1943 hull
front is listed there as 45mm at 60° from vertical; Sherman M4A1 (75mm) hull
front as 51mm at 47° from vertical; Churchill Mk VII hull front as 152mm at
0° (not sloped, per `counters/toe/british_vehicles_1943.md`). Once a K-factor
is fit from the calibration data above and run through this project's own
angle/effective-thickness formulas, comparing the resulting PaK 40 AV-vs-range
curve against these three already-sourced armor figures would give a
same-spirit sanity check to the one this project already relies on
elsewhere (e.g. its 17-pounder-vs-Tiger Appendix-9 firing-test validation) —
but that computation is explicitly out of scope for this research-only file.

## Confidence Notes

- **PzGr 39 muzzle velocity (790 vs 792 m/s):** effectively resolved — the
  two figures are close enough (0.2%) that either is fine; not a real
  discrepancy, just two independently-arrived-at near-identical numbers.
- **PzGr 40 muzzle velocity (990 vs 933 m/s):** a **real, unresolved
  discrepancy** (~2.9%) between the German factory document and the
  Aberdeen/British Ordnance Board test data. Not resolved this session —
  flagged for a deliberate pick, same as this project's existing 17-pounder
  APCBC MV note.
- **PzGr 39 Set 1 (30°, German document via Wikipedia, cross-checked by
  Panzerworld):** well-established — two independent citations of period
  German ordnance documents converge to within 1-2mm at every range point.
  This is the recommended calibration set, and it already matches this
  project's existing 30°-obliquity convention for every other German gun row.
- **PzGr 39/40 Set 2 (Aberdeen/British Ordnance Board, panzer-war.com
  `tGer01`):** moderate-high confidence — a named, real secondary book
  (Hoffschmidt 1979) reproducing period Allied test data, comparable in kind
  to this project's existing Woodman-table rows, but the exact column
  (yard-range) alignment required parsing the page's raw HTML by hand after
  the site's old table markup defeated automated text extraction — double-
  checked directly against the underlying HTML `<td>` cells (see Sources),
  not just skimmed rendered text, so alignment should be reliable, but this
  is a single fetch, not independently re-verified against print.
- **PzGr 39 Set 3 / panzer-war.com `tR01` (normalized "RHA BHN 270" table):**
  explicitly the lowest-confidence set — the site's own author describes it
  as his personal normalized compilation, not a direct primary-table
  reproduction. Included only as a cross-check; do not weight it equally
  against Sets 1/2 in any fit.
- **K-factor, both natures:** genuinely not found as a stated, ready-to-use
  number specific to PzGr 39/40 in the PaK 40 — consistent with this
  project's general pattern (per `guns.csv`, every gun's K-factor is a fit
  from calibration points, not a book-quoted constant). One tantalizing but
  ultimately inapplicable lead was found (Bird's stated K=2600 for the
  75mm/L48 **HE** round specifically) and one unconfirmed forum claim that
  Bird & Livingston's book treats this gun/round family at all (without a
  recoverable number) — see Sources.
- **Crew size (6):** single source, but a specific, page-cited reference
  book (Foss 1977) — same confidence tier as most single-citation figures
  elsewhere in this project's TOE files.
- **Divisional Panzerjäger-Abteilung organization (TM-E 30-451):** well-
  established for the *as-of-September-1943* organizational snapshot (a real
  period US Army intelligence document, already this project's backbone
  source for `germany_1943.md`), but that snapshot itself shows the
  battalion still 50mm-armed with only a separately-named "heavy" variant
  using 7.5cm guns — meaning the TOE evidence for exactly *when* in 1943 (if
  at all, at the standard-battalion level) the divisional Panzerjäger-
  Abteilung itself converted to PaK 40 is incomplete. Treat as a genuine,
  not-fully-closed organizational question, not a confirmed date.
- **Regimental Anti-tank Company (Kennedy):** confirmed to exist and confirmed
  to include 7.5cm PaK guns among a "bewildering mixture" by 1943, but no
  specific 1943-era (pre-Type44) platoon/gun-count breakdown was found —
  only the later Type44 reorganization is broken out in Kennedy's document
  in any detail.
- **Morale/quality tier:** not found at all — flagged explicitly rather than
  assumed. Do not treat "veteran anti-tank specialists" as sourced; it is
  presented here only as a commonly-heard informal claim.
- **Historical validation (specific kill at range):** not found — the closest
  real material is general qualitative assessment (Wikipedia) plus a
  documented but PaK-40-unspecific mass-Sherman-loss engagement (Kasserine/
  Sidi Bou Zid, dominated in the sources found by 88mm guns) plus archival
  German tactical doctrine (Tank Archives) rather than an actual after-
  action kill claim.

## Open Questions / Gaps for Follow-up

   the calibration points above via `fit_gun_curve`, per this project's
   normal practice.
2. The PzGr 40 muzzle-velocity discrepancy (990 m/s German document vs 933
   m/s Aberdeen/British Ordnance Board) is unresolved — needs a deliberate
   pick (or a note explaining the source of the gap, e.g. different propellant

3. Three Axis History Forum threads that plausibly discuss a Bird &
   Livingston-sourced PaK 40 K-factor or table directly could not be fetched
   this session (HTTP 403 on direct WebFetch) — only searched via snippets.
   A follow-up session with a different fetch method (e.g. a logged-in
   browser session) could potentially close the K-factor question directly
   rather than falling back to a fit.
4. The exact 1943 date (if any) at which the *standard* (non-"heavy")
   divisional Panzerjäger-Abteilung itself re-equipped from 50mm PaK 38 to
   75mm PaK 40, as opposed to the separately-named "heavy antitank
   battalion" already using PaK 40 per TM-E 30-451 (Sept 1943), was not
   pinned down. A scenario set early-in-1943 may be more historically
   accurate fielding the infantry regiment's own Anti-tank Company's PaK 40
   platoon (per Kennedy) than the divisional battalion.
5. No 1943-era (pre-Type44) platoon/gun-count breakdown of the Infantry
   Regiment's own Anti-tank Company was found — Kennedy's document only
   gives that level of detail for the later Type44 reorganization, which is
   outside this project's nominal 1943 scope.
6. No citable source for an anti-tank crew morale/quality tier was found —
   if the designer wants this gun's crew rated above/below a standard
   infantry morale tier, that would currently be a design decision, not a
   sourced fact.
7. No specific, dated, ranged combat instance of a PaK 40 killing a named
   Sherman/T-34/Churchill was found — the Kasserine/Sidi Bou Zid engagement
   is the closest real 1943 mass-loss event but the sources found emphasize
   88mm guns over the 75mm PaK 40 specifically. A source with an actual unit
