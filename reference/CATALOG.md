# Reference Library Catalog

Local WWII reference library (PDFs/EPUBs, gitignored via `*.pdf` in
`.gitignore` — this directory and its contents are not tracked in git).
Used to source rules text and roster data for *With Deepest Regret...*,
following the research methodology logged in
`docs/superpowers/specs/2026-09-10-rules-gap-audit.md` and
`docs/source/appendix_e__design_notes.rst` (design notes E.133 onward).

**Filenames are not trustworthy on their own.** Several files in this
library have filenames that do not match their actual contents (see
Flags column below) — always trust the *Verified Title* column, which was
confirmed by opening the file itself (cover page, copyright page, or
extracted text), not by reading the filename. When adding a new book,
verify it the same way before citing it in a research file.

Organized into subfolders by primary subject. A book that spans two
categories is filed under its primary use and cross-referenced in Notes.

## Maintenance

When a new book is added to any subfolder here, or an existing one gets
read by a research pass: verify its real title/author from the file
itself (not the filename) if not already confirmed, add or update its row
above, and record which `counters/toe/*.md` file and `E.###` design
note(s) cite it under "Used In."
